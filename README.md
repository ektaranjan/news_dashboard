# 📰 Daily Intelligence Brief

A live news intelligence dashboard built using Flask that aggregates and displays top headlines from major Indian and international news sources in real time.

## 🚀 Features

- Live news aggregation using RSS feeds
- Multi-source coverage from:
  - BBC
  - Indian Express
  - Hindustan Times
  - Mint
  - Financial Express
  - The Hindu
- Responsive mobile-friendly UI
- Clean news summaries with HTML parsing
- Cloud deployment using Render
- Real-time updates from multiple verified outlets

---

## 🛠️ Tech Stack

- Python
- Flask
- HTML/CSS
- RSS Feed Parsing
- Requests Library
- Render Deployment
- Git & GitHub

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/lionrohit/news-dashboard.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python python_news_dashboard.py
```
